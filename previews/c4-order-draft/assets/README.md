# Local PDF font

Unmodified Noto Sans Regular, distributed under the [SIL Open Font License](OFL.txt).
Bundled into the isolated preview; no font request is made at runtime.

- Source: [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/blob/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans/NotoSans-Regular.ttf)
- Upstream commit: `ffebf8c1ee449e544955a7e813c54f9b73848eac`
- File SHA-256: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`

This font supports Latin, Greek and Cyrillic. The exporter refuses unsupported
characters explicitly; text/CSV remain available. Broader script coverage and
accessible tagged PDF are separate work before a production export workflow.
